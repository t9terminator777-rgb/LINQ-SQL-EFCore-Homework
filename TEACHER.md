# Сообщение преподавателю

Здравствуйте! Выполнил отдельный учебный проект на C# по темам LINQ, SQL и Entity Framework Core. В проекте реализованы Web API для пациентов, медицинских справок, каталога видов справок и записи на приём; CRUD-операции, валидация, связи между моделями, демонстрационные данные и примеры LINQ-запросов. Для проверки API откройте Swagger после запуска проекта. Также добавил файл с примерами SQL-запросов.

Ссылка на GitHub: https://github.com/t9terminator777-rgb/LINQ-SQL-EFCore-Homework

Для демонстрации запущу приложение в VS Code, открою Swagger, покажу GET-список, создание записи через POST, запрос с фильтром LINQ и ответы с кодами 200/201/400/404/204.
